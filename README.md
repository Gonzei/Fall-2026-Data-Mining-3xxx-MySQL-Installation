## ⚠️ Two things to know before you start

**1. You will create a password during setup. Write it down.**
The installer asks you to make up a password for the "root" account. It is not
your laptop password — it's a brand-new one you invent on the spot. There is no
"forgot password" option, and losing it means reinstalling from scratch.

**2. Workbench will show a warning the first time you connect.**
It says something about an *"incompatible/nonstandard server version."* This is
expected and completely harmless — Workbench 8.0.47 is simply older than Server
26.7.0 and says so. Tick **Don't show this message again** and click
**Continue Anyway**. The guide explains this in full.

## 🛟 If you get stuck

Getting stuck is normal — installing a database is genuinely fiddly, and
experienced programmers hit these same errors.

1. Check the **"When Something Goes Wrong"** section of the guide. Nearly every
   problem students hit is listed there with a fix.
2. Still stuck? Bring your laptop to office hours or lab, and be ready to say:
   - Windows or Mac, and which version
   - Which step you reached before it went wrong
   - The exact error message — a screenshot is ideal

## For instructors and TAs

The Word file is generated from the Markdown source, so edit
[`docs/mysql-setup-guide.md`](docs/mysql-setup-guide.md) and rebuild rather than
editing the `.docx` directly.

```bash
pandoc docs/mysql-setup-guide.md \
  -o docs/MySQL-Setup-Guide.docx \
  --reference-doc=tools/reference.docx \
  --toc --toc-depth=2
```

`tools/reference.docx` carries the page styling (fonts, heading colours, callout
boxes, table borders). It is itself generated by
[`tools/build-style-reference.py`](tools/build-style-reference.py), which patches
pandoc's default template — you only need to re-run that script if you want to
change the visual design.

### Updating version numbers

The guide targets the versions listed above. If the course moves to different
releases, update: the download tables in the guide's *Before You Start* section,
the links in this README, and the compatibility-warning note (which is only
relevant while Workbench and Server versions are mismatched).
